💪 BeastLog — React + Firebase

BeastLog is a workout tracker I built with React and Firebase. Users can log their workouts, edit entries, and track progress — all in real time. I used React Hooks for state management and Firebase Authentication to secure user access. Workout data is stored in Firestore, which syncs instantly across devices. The UI is clean and responsive, styled with Material UI and custom CSS. This project was a fun way to combine frontend interactivity with a cloud-based backend service.
