🛒 Shopping Cart Database — SQL

This is a backend database project where I designed a full shopping cart system using SQL. I created tables for Users, Products, Orders, and Checkout, and used primary/foreign keys to link everything together. I wrote JOIN queries to simulate real-world scenarios like viewing a user's order history or cart contents. It was a great exercise in relational database design, normalization, and writing efficient queries.
