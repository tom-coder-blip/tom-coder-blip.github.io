🧳 Spring Boot Backend Project

This is a Lost & Found management system built with Spring Boot that allows users to report lost items and post found items. The system includes secure user authentication, RESTful APIs, and a clean backend architecture. It's designed to help communities manage lost and found items efficiently.

Tech Stack:
Backend: Spring Boot (Java), JWT authentication, Spring Security, PostgreSQL for data storage, Docker for deployment.
Tools: Postman for API testing, Git/GitHub for version control, Render for cloud deployment.

In short, it's a secure and scalable backend system tailored for lost & found item management.
